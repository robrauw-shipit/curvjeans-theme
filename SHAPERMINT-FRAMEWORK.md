# Shapermint Framework Reference (for CURVS rebrand)

Source: Shapermint homepage PDF + PDP/collection HTML saved 2026-07-28 to Desktop.
CURVS replicates this FRAMEWORK, styled in CURVS brand (Warm Bone/Charcoal/Blush,
NOT Shapermint coral). Product cards = real theme cards + Shapermint badge treatment.

## Shapermint real colors (reference only — we use CURVS palette)
- Charcoal ink `#292929` (≈ CURVS Charcoal #1C1C1C)
- Coral accent `#f7a08b` → REPLACE with CURVS Blush #E7C4C7
- Sale red `#882a2b`
- Greys `#f7f7f7` `#efefef` `#e5e5e5`; soft blush `#fcd9d1` `#dbbfbf`
- Yellow badge `#F2D96F` (SELLING FAST)
- Fonts: AvenirNextLTPro body + Jost headings

## Badges (seal SVGs, 24px tall bars)
- SELLING FAST = yellow #F2D96F bar
- BEST SELLER = white bar
- CLEARANCE / FINAL SALE = red variants
CURVS: keep the flat-bar badge shape; recolor to charcoal/blush/red on brand.
